# 听后回应练习器

安装 Python 3.10 或更高版本，在本目录运行 `python3 server.py`（Windows 可用 `py -3 server.py`），然后打开 http://127.0.0.1:18765 。练习器导入了用户提供的 PDF：257 套、2046 题；题干、四个选项与文末参考解析按套题及套内题号匹配。原题中疑似措辞问题保留，不擅自改写，不保证原资料的真题来源或参考答案质量。

## 开始练习

1. 右上角“语音设置”：填入阿里云百炼 API Key，选择 Key 所属地域（北京或新加坡），点击“保存并试听”。
2. 选择“日常练习”“限时挑战”或“错题复习”，再选择题目来源和每组数量。
3. 点击“开始练习”，播放题干，听完后选择 A–D，再提交答案。
4. 日常练习可重听和使用 0.8/1.0/1.2 倍速；挑战按 1 倍速只播放一次，并在整组结束后揭晓原文与解析。每题 10/15/20 秒是可选训练设置，不代表 ETS 官方考试限时。
5. 使用 A–D 或 1–4 键选择；Enter 提交/下一题，按钮获得焦点时保留按钮自身键盘行为。

“所选套题全部”按原套顺序练习；选择“随机题目 · 全部题库”时，“全部”仍限制为随机 20 题，避免一次启动 2046 题。错题记录保留曾错历史及最近结果，答对不会删除曾错记录。

## 云端语音与连读弱读

模型为 `qwen3-tts-instruct-flash`，`language_type=English`，通过官方 `instructions` 控制自然美式语调、连读、功能词弱读、适度闪音、语义重音和对请求/疑问/陈述的恰当语调。要求原文逐字保留，不加引导语、编号、背景音乐，不故意逐词慢读。语音来自 AI 合成，并非 ETS 原录音；指令是质量目标，连读和弱读实际效果仍需试听验证。

Serena、Ethan、Cherry 是官方文档列出的支持 Instruct 模型和英语的系统音色；不选择只支持普通 Flash 模型的 Aiden/Jennifer，以免指令接口与音色不兼容。

每题首次播放生成 WAV，并保存到 `audio/`；同一题干、音色、模型、朗读指令共享一个缓存文件。换音色会生成另一份音频。网页倍速播放不会重新生成文件。生成使用用户的百炼额度，没有自动预生成全部题库，避免无意产生大批调用。

API 使用官方文档的非实时 HTTP 端点，北京 `https://dashscope.aliyuncs.com`，新加坡 `https://dashscope-intl.aliyuncs.com`。非流式返回临时 OSS WAV 地址，练习器下载到本地后可继续播放，不依赖地址长期有效。

## 密钥与练习记录

Key 只保存到本机 `~/.config/toefl-response/credentials.json`，文件权限 600。网页不将 Key 写入 localStorage，也不回显已保存的 Key；服务端日志不打印请求体和 URLs。设置页可移除本机密钥。前端仅请求固定题库中的题目，不能提交任意云端 URL 或任意文本。服务只监听 127.0.0.1，云端生成路由要求页面会话令牌并拒绝跨站请求。

练习记录及当前组进度保存在浏览器 localStorage。切换浏览器会使用不同记录；可通过“导出/导入”在浏览器间转移 JSON 记录。导入以较新的累计次数覆盖同一题，避免重复导入翻倍。

挑战中途刷新不会重新获得播放机会：已开始听题的题目会显示选项，可继续回答。已启动的计时使用保存的绝对截止时间，刷新不重置倒计时。
